# C Programming Language

A collection of **55 C programs** created while learning and practicing the fundamentals of the **C programming language**.

This repository contains simple programs covering core concepts, syntax, logic building, and basic problem-solving in C.

## 📚 Contents

The programs in this repository cover topics such as:

* Basic C syntax and structure
* Variables and data types
* Input and output
* Operators
* Conditional statements
* `if`, `else if`, and `else`
* `switch` statements
* Loops

  * `for`
  * `while`
  * `do-while`
* Nested loops
* Arrays
* Strings
* Functions
* Basic problem-solving programs
* Mathematical and logical programs

## 📂 Programs

This repository currently contains **55 C programs**, ranging from basic beginner exercises to programs that practice fundamental programming concepts.

Each program is intended to demonstrate a specific concept or approach in C.

## 🎯 Purpose

The main purpose of this repository is to:

* Practice C programming fundamentals
* Improve problem-solving and logical thinking
* Keep track of my learning progress
* Build a collection of C programming examples
* Create a reference for revising basic C concepts

## 🛠️ How to Run

You can compile and run the programs using any C compiler.

### Using GCC

```bash
gcc program.c -o program
./program
```

On Windows:

```bash
gcc program.c -o program.exe
program.exe
```
